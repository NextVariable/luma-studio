## 验收范围

- 历史镜头继续绑定原资产版本。历史无摘要批准仍可使用并标为旧版。已启用批准记录的作品执行视图门槛。旧制作计划补充了文件摘要，升级前排队且从未提交的请求如果无法通过重算，需要重新报价。已经接单的任务仍按原任务号或已保存结果恢复。
- 生成请求与资产操作仍在原 SQLite、Dify、媒体适配器和 FFmpeg 路径上。现有本机 HTTP 来源限制、凭据隔离、禁止自动转发认证请求和素材下载公网校验保持有效。本机授权是调用次数控制，实际金额取决于供应商账单。
- 没有远程任务号、也没有可下载产物的方舟请求仍需人工查账确认；工作室没有足够依据自动重发。原 PR 的 CI 只覆盖原 HEAD，修复分支使用本地全量回归。真实账号下的模型协议、实际扣费、角色一致性、画质和成片均须另行验收。

最终本地回归通过 449 项 Python 和 24 项 JavaScript 测试。Python 包含 17 项独立审计回归和一项新增的本机 HTTP 上传用例。Ruff、运行依赖检查和 Git 差异检查通过。

**判断 A。修复分支具备进入小批量真实 AI 成片验收的条件。** 建议以独立验收库、每镜单次授权、遇到未确认任务即停为测试条件。正式交付仍需验证真实图像质量、视频稳定性、配音字幕和成片可播放性，并以供应商账单核对真实费用。
