# V0.3 分镜视觉制作与验收

## 视觉设定

作品的创作设定保存统一画风。展开「视觉设定」可以补充色彩与光线、服装连续性、摄影与景别。角色与场景仍使用镜头已经绑定的资产版本。一套视觉设定适用于同一作品的各集。旧作品可以继续沿用原配置。

| 用途 | 权威来源 | 进入 Seedream 的方式 |
| --- | --- | --- |
| 角色 | 镜头绑定的角色造型版本 | 经批准的指定图片优先。旧项目沿用该版本的主图、四分之三侧视图或正视图 |
| 场景 | 镜头绑定的场景版本 | 名称与描述进入提示词。明确批准该版本的图片后，其图片也进入请求 |
| 构图 | 镜头保存的本地机位预演 | 默认传构图图，并标明用途。文字机位模式只传景别、站位、视线和画外关系 |
| 画风 | 作品统一画风和视觉设定 | 默认传文字。批准作品级风格资产版本后，Seedream 也接收该图片 |

图片审批通过现有作品保存接口写入 `creative_brief.visual_bible.references`。每条记录包含 `role`、`asset_id`、`version_id`、`file` 和 `source`。文件须属于该版本。列表只包含已经人工同意用于生成的参考图。角色旧引用标为 `legacy`，本地构图标为 `composition_only`。场景或风格资产有图片本身并不意味着该图已获批准。每个角色或场景版本只批准一张，作品风格图最多一张。使用新定妆版本时还需明确将目标镜头绑定到该版本。

实验可通过现有分镜报价与生成接口使用 `storyboard_reference_mode: "text"`。报价接口只预览，提交生成仍需匹配报价和生成授权。fal 保留原有机位图请求模式。图片按角色、场景、构图、风格顺序传送，提示词通过图序号明确用途。结果保存为候选，沿用正常人工选用流程。

## 第二镜实验

| 组 | 固定条件和改变项 | 费用及验收状态 |
| --- | --- | --- |
| A | 使用最近一次真实分镜及历史任务的输入与参数 | 历史报价 ¥0.12，实际账单待核对 |
| B | 同一模型、画幅、场景、角色版本与角色图，移除机位图；以文字指定腰上取景、画左三分线、视线朝右 | 当前报价 ¥0.12，待授权 |
| C | 沿用 B 的文字机位。改用经批准的高清单人定妆图，并加入基于作品的美术约束 | 定妆图待提供和批准。按当前单张报价预计 ¥0.12，待重新报价与授权 |

C 的初始创作方向为精细手绘二维动画、清晰的五官与眼神、细腻的衣料褶皱和有层次的夜景。保留现有蓝色外套、黑短发、冷蓝环境与暖色顶灯，可根据最终定妆图调整。首轮 C 先用文字风格约束，避免额外引入风格图这个变量。

A 是历史基线。A/B 比较同时改变了构图的输入媒介及相应文字，B/C 同时改变定妆图及美术约束，只能比较两套流程的表现。单次出图受模型随机性影响。后续若要拆分变量，可分别测试只换定妆图与只改风格文字，再做重复采样。先保持同一 Flash 模型。

逐组存档模型、按顺序列出的文件及 SHA-256、实际提示词、请求参数、报价、服务商请求 ID 与用量、实扣状态、结果和人工评语。失败后保留记录。任何新增调用需单独获得预算授权。

## 人工质量门槛

- **结构检查**逐项标为通过、失败或不可判断。包括角色身份和人数、服装、视线与构图、景别、环境和相邻镜头的连续性。结构错误须处理后再送审。不可判断的项目继续人工核对。
- **美术检查**分别评价画风一致性、表情可读性和美术精细度，每项 1 至 5 分。1 分为明显不足，3 分为可用但需斟酌，5 分为达到作品视觉目标。建议每项至少 3 分，并由创作者确认是否采用。
- 人工评语应写出画面依据。模型或程序可以标出疑点，审核人确认最终判定。离线测试仅证明输入构造正确。
