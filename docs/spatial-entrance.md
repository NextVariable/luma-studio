# 流幕空间开场

运行 `python3 -m luma` 后打开首页。每个浏览会话首次进入时展示开场，`/?entrance=1` 可以重放，`/?entrance=off` 直接打开工作室。`/spatial-preview.html` 是独立原型入口，转场后接入同源真实工作台。开场的「前进」「后退」与滚动共享同一条摄影机轨迹。进入工作台后，右上角「后退」把镜头拉回空间，并保留当前工作台状态。

## 从空间到工作台

- `web/spatial/renderer.js` 用 WebGL 把日光客厅影像投影到房间和近景家具表面，并绘制带分段的圆弧网格、中央屏和半透明的近景人物。人物以独立纹理平面放置在屏幕前方，沙发挡住下半身。摄影机移动时，世界坐标中的投影表面和屏幕产生视差。
- `web/spatial/art.js` 将剧本、人物与场景、放映画面、分镜和时间线画入纹理。正式入口优先读取当前作品的只读数据，预览使用仓库自带的三镜分镜和独立创作的《夜晚站台》概念图。
- `web/spatial/entrance.js` 从原生滚动位置计算摄影机轨迹，推近至正视中央屏。最后将原工作台映射到中央屏的投影矩形，连续交接到视口。转场结束后移除开场节点、恢复工作台交互、释放 WebGL 资源。
- 画面动态设置像素比上限并暂停后台标签渲染。禁用 WebGL 或开启减少动态效果时提供日光客厅底图和进入按钮。桌面鼠标、触屏和键盘可以控制开场。

## 复验

用 `node --test tests/*.test.js` 校验桌面与竖屏投影对齐及摄影机轨迹。浏览器中打开独立预览，向下推进后反向返回，再滚动到底并打开工作台设置。刷新正式入口时直接显示工作台。在 Chrome 的移动模式、减少动态效果及禁用 WebGL 的环境中分别复验。

《夜晚站台》概念图为本入口原创生成艺术，未作为作品正式生成候选保存。三镜联系表取自仓库内的演示样片。日光客厅底图根据用户提供的房间参考重建。
