## 用户完整操作路径

1. 在「剧本」录入故事，用 Dify 获取资产和分镜建议，审阅后采纳。
2. 在「角色」生成阿远、青禾和站台候选。审图后为通过的结果新增版本。每个角色或场景版本可按视图逐张批准，登记用途、来源及哈希；同一版本可同时批准正面、侧面、四分之三和背面，场景可批准设定图、全景、细节和反打。导入风格图并作为作品风格参考批准。资产生成会自动带上最多 3 张既有视图和 1 张已批准画风参考，并写入成稿质量约束。
3. 在目标镜头明确绑定批准的版本。「制作 → 基础」显示实际选择的参考及原因，可调整机位、查看分镜报价并进入候选复核。高级模式保留分段、起止状态、参数与拼接。
4. 结构项全部通过且美术项每项至少 3 分后，选用核对过的图片作为视频共同首帧。两家共享首帧、动作和时长。Wan 720P 与海螺 768P 的分辨率是供应商差异，解释比较结果时记入。
5. 比较视频动作、身份稳定性、运镜、耗时、费用，选择候选。人工复核发现问题可带评语进入原单镜改写。先预览改动，确认后只更新受影响镜头。
6. 核对逐句对白音轨、字幕、所选画面和交付清单，打开“制作证据”确认每条候选的来源、评分和费用，导出 MP4。原成片与候选历史可复查。

## 风险与发布判断

- P0：缺两条真实制作链。正式资产、人物和场景一致性尚未通过人工验收。Wan 与 MiniMax 当前账号上的真实响应与价格也待核对。
- P0：离线测试能够覆盖异常状态和重启后查询原任务，但还需在真实供应商环境验证入库重试、下载有效期和实扣。
- P1：Dify 方案和成片画质证据之间目前以人工复核为主，尚无独立视觉模型审核。对照不能控制供应商分辨率差异。
- P1：基础工作台已检查两个作品，仍需新用户完成创作任务并记录真实干预及返工次数，移动端也需完整验收。

当前可作开发者预览。公开 Beta 需先通过两条真实交付与新用户验收，正式发布还需重复制作与费用一致性证据。
