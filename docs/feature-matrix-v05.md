## 本轮实施顺序

1. **P0 视觉资产**：多视图参考批准、资产生成注入风格与多参考、成稿质量约束。
2. **P0 工作台**：基础模式显示画风与参考状态，补“单镜返工”入口。
3. **P1 可靠性**：补充引用一致性、旧项目兼容、密钥泄露回归测试。
4. 全量 Python/Node/Ruff 回归，浏览器复验，按模块提交。
5. 推送 `dev/trae-luma-v05` 并准备 PR 正文；若仍 403，如实报告，不伪造链接。

## 明确不能在本轮声称完成的内容

- 真实 Seedream / Wan / MiniMax / Dify 付费运行与画质结论。
- 历史样片“低多边形人物、简单五官、场景连续性差”的真实改善幅度。
- 正式作品的人工美术评分与生产级验收。
