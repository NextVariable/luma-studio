## V0.5.1 实施结果

1. **P0 参考图门禁**：`asset_image_packet` 与 `storyboard_packet` 默认只使用已批准视图；未批准视图进入请求前必须显式确认，并返回排除清单与预览。
2. **P0 版本语义**：新版本不继承旧版本批准，选用/恢复版本不改写已有镜头绑定；界面显示批准数、视图数、绑定镜数和未批准提示。
3. **P0 风格感知**：新增 `luma/art.py`，区分二维动画/赛璐璐、国漫插画、电影写实、自定义；动画提示词不再要求真实皮肤。
4. **P1 证据与返工**：候选与交付证据显示本地/供应商记录/记录缺失，明确模拟记录不等于真实 API 验收；单镜返工隔离回归通过。
5. **测试**：431 项 Python、23 项 JS、ruff 通过；浏览器复验项目加载、美术风格选择、批准徽章与基础制作步骤；未发起真实付费调用。
6. **剩余验收**：真实 Seedream / Wan / MiniMax / Dify 运行、真实画质与低多边形改善、新用户与移动端体验仍需付费或人工验收。

## 明确不能在本轮声称完成的内容

- 真实 Seedream / Wan / MiniMax / Dify 付费运行与画质结论。
- 历史样片“低多边形人物、简单五官、场景连续性差”的真实改善幅度。
- 正式作品的人工美术评分与生产级验收。
