# Code of conduct · 行为准则

This applies to issues, pull requests and discussions in this repository.

- Discuss the work. Respect other people's time, background and opinions.
- Support feedback with reproducible facts. Questions and corrections are welcome.
- Respect privacy and credit. Get permission before posting other people's material.
- Harassment, personal attacks, discrimination and publishing private information without consent will be removed.

Report violations through the private channel in [SECURITY.md](SECURITY.md). Maintainers may edit or remove content and limit participation as needed.

适用于本仓库的 Issue、Pull Request 和讨论。请围绕具体问题交流，用可复现的事实支持反馈，发布他人资料前先取得授权。骚扰、人身攻击、歧视和未经许可披露私人信息的内容会被移除。如遇到违规行为，请通过 [SECURITY.md](SECURITY.md) 中的私密渠道向维护者报告。
